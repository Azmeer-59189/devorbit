Website names and column headings stay visible while scrolling. Status colors also have text labels; notes and long remarks can be expanded.
- Editing either page preserves the entire saved form payload, including fields owned by the other page. Review counts, visible history fields and exports follow the selected page. Category filters also apply to export columns. Maintenance dates remain reference dates.

No SQL migration is needed. Existing SEO URLs remain valid. Local tests cover routing and the complete, non-overlapping field split. Browser appearance remains unverified.
